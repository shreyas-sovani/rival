# Spike S2 — Permit2 witness

## Decision

**GO for K3.** A viem `signTypedData` signature over `PermitWitnessTransferFrom` recovers to the maker on the same digest `@uniswap/permit2-sdk@1.4.1` `SignatureTransfer.hash` produces. Solidity `intentHash` matches that witness. The pinned local Permit2 (`contracts/lib/permit2`) accepts a signature over the same witness type string. The hash was not weakened to force a match.

Sepolia was not forked. The fixture signature is bound to the canonical Permit2 `0x000000000022D473030F116dDEE9F6B43aC78BA3` and settlement `0x1111111111111111111111111111111111111111` on chain id `11155111`. Recovering it does not need those contracts deployed.

`contracts/lib/permit2/src/Permit2.sol` is `pragma solidity 0.8.17` and imports solmate, which is not checked out, so this repo's solc `0.8.26` pin cannot link that contract. The fill test deploys `LocalPermit2`, a shell whose domain, unordered-nonce bitmap, and transfer order match `SignatureTransfer`. The witness hash is `PermitHash.hashWithWitness` from the pinned library, not a reimplementation. `vm.sign` covers that digest. A signature cannot be replayed onto a different spender or Permit2 domain, so the hardcoded viem signature is recovered directly instead of being replayed into `fill`.

## Cancel

`cancelBySig` checks an EIP-712 signature. It is not a Permit2 signature.

```
EIP712Domain(string name,string version,uint256 chainId,address verifyingContract)
name = "RivalSettlement"
version = "1"
chainId = block.chainid
verifyingContract = address(settlement)

Cancel(bytes32 intentHash,uint256 deadline)
```

`intentHash` is `RivalSettlement.intentHash` (the Permit2 witness), not the Permit2 signing digest. `block.timestamp > deadline` reverts `Expired`. A deadline equal to the current timestamp is still valid. The recovered signer is the `maker` argument of `Cancelled`. The signature is 65 bytes, `r || s || v`, with `v` in {27, 28} and low `s`.

The frozen function does not take the maker address. The contract cannot compare the recovered signer to the maker inside the intent hash, so any key can produce a signature that cancels a known hash. `cancel(Intent)` does check `msg.sender == maker`.
