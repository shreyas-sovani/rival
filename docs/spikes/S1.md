# Spike S1 — RivalOracleHook

## Decision

**GO for the hook design (K2).** Unit parity on 1,000 sequences passed (`test_modelParity`). The Sepolia fork test `test_fork_initializeHookedPool` initialized a fee-500, tick-spacing-10 pool on the canonical PoolManager `0xE03A1074c86CFeDd5C142C4F04F1a1536e203543`, added liquidity, and swapped once. The live fork was not skipped.

K2's ABSOLUTE-only fallback triggers only if a hooked pool cannot be created, or model parity fails and stays unresolved. Neither happened.

If `SEPOLIA_RPC_URL` is unset, the fork test calls `vm.skip` and does not fail the suite. That skip is not a K2 failure. A skip-only run is still GO for the design, with the live fork explicitly not exercised.

## Flag mask

Permissions are `afterInitialize` and `beforeSwap` only. No delta-return flags and no fee override.

| Flag | Bit |
| --- | --- |
| `afterInitialize` | `1 << 12` (`0x1000`) |
| `beforeSwap` | `1 << 7` (`0x80`) |
| mask | `0x1080` |

`Hooks.ALL_HOOK_MASK` is the low 14 bits (`0x3fff`). `test_permissionsBitmap` checks `getHookPermissions`, `Hooks.validateHookPermissions`, and `Hooks.isValidHookAddress`.

## Salt mining

`BaseHook` rejects a deploy whose address flags do not match `getHookPermissions`. Tests and `scripts/spikes/s1-hook.ts` use the v4-periphery search:

1. `initcode = type(RivalOracleHook).creationCode ++ abi.encode(poolManager)`
2. For `salt` from 0 upward, compute `CREATE2(deployer, salt, keccak256(initcode))`
3. Accept the first salt where `(address & 0x3fff) == 0x1080` and the address has no code
4. Deploy with `new RivalOracleHook{salt: salt}(poolManager)`

In Foundry the deployer is the test contract (`HookMiner.find(address(this), ...)`). A forge-script broadcast would use the CREATE2 deployer proxy `0x4e59b44847b379578588920cA78FbF26c0B4956C`. This spike does not broadcast: there is no operator key, and `scripts/spikes/s1-hook.ts` only checks the mask and prints the search.
